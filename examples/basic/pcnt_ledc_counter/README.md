# PCNT LEDC Counter

Validates `esp32libfun_pcnt` by counting a PWM signal generated by
`esp32libfun_ledc`.

## Wiring

For the ESP32-S3 validation setup:

```text
GPIO43 -> GPIO13
```

- GPIO43: LEDC pulse output
- GPIO13: PCNT input

Use other GPIOs if required by your target, but keep one output connected to one
PCNT-capable input.

## What It Tests

- PCNT rising-edge counting
- count accumulation above the hardware high limit
- LEDC-generated pulse rates from 10 kHz to 1 MHz

The default PCNT limits are `-32768..32767`. The wrapper enables ESP-IDF
accumulation and internal limit watch points, so `pcnt.count()` can report
values above `32767`.

## Run

```powershell
idf.py set-target esp32s3
idf.py -p COM5 flash monitor
```

Adjust the target and port for your board.
